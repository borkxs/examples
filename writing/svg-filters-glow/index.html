SVG filters

Glow

A glow is not one operation. It is a tiny image pipeline: blur an alpha mask, color it, clip the color to the blur, then merge the original graphic back on top.

The mental model

SVG filters are easier to read if you treat each element as producing an intermediate image. Some filter elements create pixels. Some transform pixels. Some combine pixels. The useful trick is naming the intermediate results.

This page keeps the original example's laconic style: each step changes one thing.

Takeaway

Most useful SVG filters are pipelines. If you can name the intermediate images, you can reason about the filter.

The original generated version of this example is still available at svg/filters/glow/.
